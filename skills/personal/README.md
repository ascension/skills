# Personal

Skills tied to my own setup, not promoted in the plugin.

- **[dispatch](./dispatch/SKILL.md)** — Deliver a spawn intent through a named or detected host adapter into a fresh session, in a space matched by issue, branch, or short work description. Model-invoked; `orchestrate-prd` uses it for every leg and for smart-zone rollover.
- **[land-pr](./land-pr/SKILL.md)** — Keep a pull request in a quality-gated polling loop until `/code-review` is clean on the current head and it is safely merged, or it reaches a human-only blocker.
- **[orchestrate-prd](./orchestrate-prd/SKILL.md)** — Coordinate an approved PRD ticket graph through isolated sessions on the current host, one draft PR, and a bounded review/fix loop.
- **[review-pr-comments](./review-pr-comments/SKILL.md)** — Verify automated pull-request feedback against the current diff, fix confirmed issues, push targeted changes, and report every disposition.
- **[triage-content](./triage-content/SKILL.md)** — Evaluate external links, posts, articles, and repos against Hive before deciding whether to adopt, adapt, watch, or discard them.
