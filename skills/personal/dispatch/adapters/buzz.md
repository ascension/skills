# Buzz adapter

Load only when the host is Buzz.

## Spawn

A **fresh session** is a one-shot process: new CLI/ACP invocation, no session persistence, packet as the only task context. Resolve `model` and `effort` against the runner catalog the same way the Herdr adapter does for its underlying command.

`@mention` of a standing agent fails the gate (core memory and channel history are inherited turns). `buzz agents draft-create` opens an owner-review form and is not AFK.

If this session cannot start a one-shot process that satisfies the capability probe, the probe fails. Ask for a **pin** to another host or stop as `blocked`.

## Wait and read

Wait on the one-shot process. The receipt is its stdout (or the file it was told to write). Channel replies are not a second progress channel.
